# FitBot — бот и мини-приложение для фитнес-тренера

**Хотите бесплатный вариант вместо платного хостинга?** См. `ORACLE_DEPLOY.md` —
пошаговая инструкция для Oracle Cloud Always Free (бесплатно навсегда, но с
командами в терминале). Инструкция ниже — платный вариант через Railway
(проще, но пара долларов в месяц).

Что это: Telegram-бот с анкетой для клиентов + мини-приложение (открывается
прямо внутри Telegram) с личным кабинетом клиента и отдельным кабинетом тренера.

## Что уже сделано

**Бот:**
- `/start` → анкета (имя, возраст, цель, «уже клиент или новый», удобный способ и время связи)
- тренер определяется по своему Telegram ID (задаётся в настройках, см. ниже)
- тренер присылает боту видео с подписью «Название | теги» → видео сохраняется в библиотеку
- клиент присылает боту фото еды → автоматически попадает в отчёт по питанию

**Личный кабинет клиента (мини-приложение):**
- программа тренировок на неделю по дням, с кнопкой «смотреть» на каждое упражнение
- советы по питанию и рекомендации по разминке
- отчёт по весу (форма + история)
- отчёт по питанию (форма + история)
- кнопка «Написать тренеру» — открывает обычный чат в Telegram

**Кабинет тренера (мини-приложение):**
- список клиентов, по клику — его отчёты по весу и питанию
- конструктор программы на неделю: выбор клиента, недели, дня — библиотека упражнений
  отсортирована так, что упражнения, которые этому клиенту давно не давали (или не
  давали вообще), помечены ⭐ и идут первыми
- библиотека видео (то, что вы прислали боту)

## Важное упрощение, которое стоит знать

Чат с тренером сделан через обычный чат Telegram (кнопка открывает диалог с вами),
а не как отдельная переписка внутри приложения. Строить свой чат с нуля — это
отдельный большой модуль (нужно хранить сообщения, доставлять их в реальном
времени и т.д.), а готовый чат Telegram уже прекрасно справляется с этой задачей
и ничего не теряет по сравнению со своим.

## Шаг 1. Получить токен бота

1. В Telegram напишите **@BotFather**
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`)
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxx` — сохраните его

## Шаг 2. Узнать свой Telegram ID

1. Напишите боту **@userinfobot** команду `/start`
2. Он пришлёт ваш числовой ID — сохраните его (это нужно, чтобы бот понимал,
   что именно вы — тренер, а не клиент)

## Шаг 3. Выложить код на GitHub (без терминала)

1. Зайдите на [github.com](https://github.com) и создайте бесплатный аккаунт, если его нет
2. Нажмите **New repository**, дайте название (например `fitbot`), нажмите **Create repository**
3. На странице репозитория нажмите **uploading an existing file**
4. Перетащите туда **все файлы и папки** из этого проекта (сохраняя структуру папок)
5. Нажмите **Commit changes**

## Шаг 4. Развернуть на Railway (недорогой хостинг, всё через мышку)

1. Зайдите на [railway.app](https://railway.app) и зарегистрируйтесь через GitHub
2. Нажмите **New Project → Deploy from GitHub repo** → выберите ваш репозиторий `fitbot`
3. Railway сам определит, что это Python-проект, и начнёт сборку
4. Откройте вкладку **Variables** и добавьте переменные (те же, что в `.env.example`):
   - `BOT_TOKEN` — токен из шага 1
   - `TRAINER_TG_ID` — ваш ID из шага 2
   - `TRAINER_USERNAME` — ваш username в Telegram, без @
   - `PUBLIC_URL` — пока оставьте пустым, заполним на шаге 6
5. Дождитесь, пока сборка завершится (статус **Active**)

Стоимость: у Railway есть бесплатный пробный лимит, дальше — оплата по факту использования
(обычно 1–5 $ в месяц для такого маленького проекта).

## Шаг 5. Включить постоянное хранение данных (важно!)

Без этого шага база данных будет обнуляться при каждом обновлении кода.

1. В проекте на Railway нажмите **+ New → Volume**
2. Путь монтирования (**Mount path**) укажите: `/app`
3. Прикрепите том к вашему сервису

## Шаг 6. Получить адрес приложения и включить Mini App

1. В настройках сервиса на Railway откройте **Settings → Networking → Public Networking**
   и нажмите **Generate Domain** — получите ссылку вида `https://fitbot-production.up.railway.app`
2. Скопируйте её и впишите в переменную **PUBLIC_URL** (шаг 4.4) — сохраните, сервис перезапустится
3. Снова напишите **@BotFather** → `/mybots` → выберите вашего бота → **Bot Settings → Menu Button**
   → **Configure Menu Button** → вставьте туда ту же ссылку (`.../client` работать не обязательно,
   бот сам присылает кнопки с нужными адресами `/client` и `/trainer` при `/start`)

## Шаг 7. Проверка

1. Напишите вашему боту `/start` с обычного (не тренерского) аккаунта — должна начаться анкета
2. После анкеты — кнопка «Открыть личный кабинет» должна открывать мини-приложение
3. С аккаунта, чей ID указан в `TRAINER_TG_ID`, напишите `/start` — должен открыться кабинет тренера
4. Пришлите боту видео с подписью `Тест | ноги` — проверьте, что оно появилось во вкладке «Видео»
   в кабинете тренера

---

## Если что-то не работает

- **Кнопка мини-приложения не открывается / белый экран** — проверьте, что `PUBLIC_URL` в
  переменных Railway указывает ровно на ваш домен, без `/` на конце, и что домен доступен
  по HTTPS (Railway выдаёт HTTPS автоматически)
- **После перезапуска пропали клиенты** — не выполнен шаг 5 (том для хранения данных)
- **Бот не отвечает** — проверьте вкладку **Deployments → View Logs** на Railway, там будет видна ошибка

## Как запустить у себя на компьютере (по желанию, для проверки перед деплоем)

```bash
pip install -r requirements.txt
cp .env.example .env    # затем впишите в .env реальный токен и свои данные
python main.py
```
